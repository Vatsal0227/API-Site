API-Site

Two different sites were hosted: the API Site and the External Site.

API Site: This was the first site hosted on AWS. I managed all the database and table information using phpMyAdmin, and all the files were in the **API_Files** folder. PHP was the primary programming language used for coding.

External Site: This was the second site hosted on AWS. It included the entire user interface and all the files from the **External_Site_Files** folder. PHP was also the primary programming language used for coding.

Since my free trial on AWS was expiring, both sites have been shut down.
